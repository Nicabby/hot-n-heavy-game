# 🎲 The Game of Lifestyle (TGOL) - Digital Edition

A sensual, cheeky party game for couples and groups, inspired by 1950s pin-up culture.

## 🌟 Features

- **Age Verification**: 18+ content protection
- **Dynamic Gameplay**: Icebreaker → Hot & Heavy → Extra Hot progression
- **Customizable Experience**: Choose categories and spice levels (L1-L5)
- **Multi-Player Support**: 2-8 players with optional partner pairing
- **Responsive Design**: Beautiful 1950s pin-up inspired UI
- **Audio Integration**: Atmospheric sounds and music (placeholder implementation)
- **Physical Store Integration**: WIX-powered e-commerce for physical card sets

## 🎮 How to Play

1. **Gather**: 2-8 players (couples or groups)
2. **Set Preferences**: Choose spice level and activity categories
3. **Consent**: Agree to guidelines and safety rules
4. **Play**: Draw cards, complete challenges, skip anything uncomfortable
5. **Heat Check-ins**: After every 18 cards, decide if you want to increase intensity

## 🛠️ Tech Stack

- **Frontend**: Next.js 14, React, TypeScript
- **Styling**: Tailwind CSS with custom TGOL brand theme
- **Data**: JSON-based card decks and player management
- **Audio**: Web Audio API with AudioManager utility
- **Hosting**: Vercel-ready deployment

2. **Run development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```

## 🎯 Game Modes & Levels

### Hot & Heavy (L1-L3)
- **L1**: Gentle touching, sensual massage, kissing
- **L2**: Passionate activities, temperature play  
- **L3**: Intimate challenges, advanced roleplay

### Extra Hot (L4-L5)
- **L4**: Power dynamics, advanced roleplay
- **L5**: Maximum spice - all categories available
